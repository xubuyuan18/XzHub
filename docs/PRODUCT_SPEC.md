# XzHub 产品需求说明

## 1. 产品定位

XzHub 是一款面向 Windows 的轻量级系统托盘状态面板，用于集中展示订阅服务用量、VPS 运行状态、网站可用性、API 配额及用户自定义服务状态。

用户无需打开浏览器或多个控制台，只需点击任务栏通知区域中的 XzHub 图标，即可查看关键服务状态。

## 2. 核心体验

- 应用可随 Windows 启动并常驻系统托盘。
- 左键点击托盘图标，弹出靠近任务栏的无边框面板。
- 再次点击托盘图标、点击窗口外部或按下 Esc 时隐藏面板。
- 点击关闭按钮只隐藏窗口，不退出后台进程。
- 通过托盘右键菜单执行刷新、设置、开机启动和退出。
- 数据采集在 Rust 后台运行，界面隐藏时仍可继续刷新。

## 3. MVP 范围

### 3.1 托盘与窗口

- 创建系统托盘图标。
- 支持左键显示或隐藏主面板。
- 支持右键菜单。
- 窗口无边框、不可调整尺寸、不显示在任务栏中。
- 支持多显示器和不同任务栏位置。

### 3.2 服务管理

- 新增、编辑、删除服务。
- 启用或禁用服务。
- 设置刷新间隔。
- 手动刷新单个服务或全部服务。
- 服务卡片支持排序。

### 3.3 首批 Provider

1. HTTP 状态检测
   - URL、请求方法、请求头、超时和期望状态码。
   - 输出在线状态、响应时间和错误信息。

2. 通用 JSON API
   - 允许通过字段路径提取状态、已用量、总量、到期时间等数据。
   - 第一版优先支持简单点分路径，后续再评估完整 JSONPath。

3. VPS Agent
   - 通过 HTTPS 请求轻量 Agent。
   - 展示 CPU、内存、磁盘、负载、运行时间和网络延迟。

### 3.4 本地数据

- 使用 SQLite 保存服务配置、应用设置和有限的历史快照。
- 密钥、Token、Cookie 等敏感信息不得明文写入 SQLite。
- 敏感凭据通过 Windows Credential Manager 或等价安全存储保存。

## 4. 非 MVP 范围

以下能力不进入第一版：

- 用户账号和云端登录。
- 多端云同步。
- 团队协作与权限系统。
- 公开插件市场。
- 远程下发任意系统命令。
- 基于 SSH 的大规模 VPS 管理。
- 移动端与 macOS 客户端。
- 商业订阅和支付系统。

## 5. 状态模型

每个服务统一输出以下状态之一：

- `online`：服务正常。
- `warning`：服务可访问，但用量、性能或到期时间达到告警条件。
- `offline`：服务不可访问或明确异常。
- `unknown`：尚未检查、配置错误或结果无法判断。

## 6. 性能目标

- 空闲常驻时避免持续高 CPU 占用。
- 默认刷新周期不低于 30 秒。
- 后台请求必须设置超时和并发上限。
- 主面板应在用户点击后快速显示，优先展示缓存数据。
- 单个 Provider 异常不得阻塞其他 Provider。

## 7. 安全原则

- 所有外部请求默认启用证书校验。
- 日志不得输出完整 Token、Cookie、密码或授权头。
- 自定义 Header 在界面和日志中必须脱敏。
- Provider 只能访问其配置明确指定的资源。
- 不允许远程接口向客户端下发任意命令。
- 数据库迁移必须可重复执行并具备版本控制。

## 8. 验收标准

MVP 被视为完成时，应满足：

1. Windows 启动应用后出现托盘图标。
2. 点击图标可以稳定显示和隐藏面板。
3. 用户可以添加至少一个 HTTP 服务并看到实时状态。
4. 关闭面板后后台刷新仍然工作。
5. 重启应用后服务配置仍然存在。
6. 网络异常不会造成应用崩溃。
7. 日志中不存在明文敏感凭据。
