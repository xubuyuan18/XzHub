# XzHub

> A Windows tray dashboard for monitoring subscriptions, VPS resources and custom services.

## Vision

XzHub aims to provide a lightweight Windows resident dashboard similar to Windows quick settings panels.

Features planned:

- Windows system tray resident application
- Floating dashboard panel
- VPS monitoring
- Subscription quota tracking
- Custom HTTP/API monitoring
- Service health status
- Local data storage

## Tech Stack

Planned architecture:

- Tauri 2
- React + TypeScript
- Tailwind CSS
- Rust backend
- SQLite
